# Пример плагина на VoidRP UI

Рабочий минимум: команда `/uidemo` открывает страницу с вкладками, плитками и кнопкой,
которая считает нажатия. Папку можно скопировать куда угодно и собирать саму по себе.

```bash
./gradlew build
# build/libs/voidrp-ui-example-1.0.0.jar → в plugins/ рядом с VoidRpUI.jar
```

Собираете рядом с исходниками движка — укажите свежий jar вместо JitPack:

```bash
./gradlew build -PvoidrpUi=../build/libs/voidrp-ui-0.2.0.jar
```

## Что здесь смотреть

| Файл | О чём |
|---|---|
| `UiDemoPlugin.kt` | как достать сервис (`VoidRpUi.get()`) и открыть страницу |
| `DemoPage.kt` | сама страница: состояние полями, `refresh()` после изменения, `onClick` |
| `build.gradle.kts` | одна зависимость, `compileOnly` — плагин уже стоит на сервере |
| `plugin.yml` | `depend: [VoidRpUI]` |

Три вещи, ради которых пример и написан:

- **`screen(...)`** — корень страницы ровно по экрану игрока.
- **`width = Size.Fill, maxWidth = 900`** — занять экран, но не растянуться в простыню на
  ультравайде. Это `max-width` с автоцентрированием.
- **`viewport.by(compact = 2, regular = 3)`** — колонок меньше на узком экране. Холст всегда
  1024 единицы в высоту, поэтому узкий экран означает *уже карточки*, а не *больше рядов*.
