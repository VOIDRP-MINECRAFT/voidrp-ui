# Вёрстка

Страница описывает, **что** на ней, а не где что лежит. Раскладка сама считает размеры и
координаты — так же, как это делает браузер. Здесь полный список того, из чего собирается
страница.

Всё, что ниже, — обычные data-классы из `ru.voidrp.ui.layout`. Они неизменяемые: страница
каждый раз строит описание заново, а движок превращает его в фигуры.

## Панель

`Panel` — единственный контейнер. Это flex-контейнер из веба: раскладывает детей в ряд или
в колонку, с промежутком и правилами выравнивания.

```kotlin
Panel(
    direction = Direction.ROW,      // ROW | COLUMN (по умолчанию COLUMN)
    gap = Theme.SPACE_3,            // промежуток между детьми
    justify = Justify.SPACE_BETWEEN,// вдоль направления
    align = Align.CENTER,           // поперёк направления
    width = Size.Fill,
    height = Size.Fixed(58),
    maxWidth = 1278,                // необязательный предел + автоцентрирование
    style = Theme.card,
    id = "top-bar",                 // панель становится кликабельной областью
    children = listOf(/* … */),
)
```

| Поле | Что делает |
|---|---|
| `direction` | `ROW` — в строку, `COLUMN` — в столбец |
| `gap` | промежуток между детьми, в единицах холста |
| `justify` | `START`, `CENTER`, `END`, `SPACE_BETWEEN` — вдоль направления |
| `align` | `START`, `CENTER`, `END`, `STRETCH` — поперёк |
| `width` / `height` | см. «Размеры» |
| `minWidth` / `maxWidth` / `minHeight` / `maxHeight` | пределы; при превышении панель встаёт по центру выделенного места (`margin: 0 auto`) |
| `style` | фон, рамка, скругление, отступы, тень, свечение — см. [стиль.md](стиль.md) |
| `id` | имя области: по нему приходят наведение и клик |

Отступы внутри панели — это `style.padding`, а не поле панели: `Style(padding =
Insets.all(16))` или `Insets.symmetric(vertical, horizontal)`.

## Размеры

```kotlin
Size.Auto              // по содержимому (по умолчанию)
Size.Fill              // всё, что осталось у родителя
Size.Fixed(240)        // ровно столько единиц
Size.Percent(0.66)     // доля от того, что даёт родитель
```

Несколько `Fill` в одной панели делят свободное место поровну. `Fill` внутри `Auto`-родителя
ведёт себя как `Auto` — делить нечего, пока размер родителя сам зависит от детей.

## Корень страницы

```kotlin
override fun view(): View = screen(
    style = Theme.scrim,
    align = Align.CENTER,
    children = listOf(card()),
)
```

`screen()` (из `ru.voidrp.ui.widget`) — панель ровно по экрану игрока: 1024 единицы в
высоту и столько в ширину, сколько даёт форма его окна. Подробности — в
[адаптивность.md](адаптивность.md).

## Текст

```kotlin
Text("Добро пожаловать", size = Theme.TEXT_H2, colour = Theme.INK, weight = Weight.BOLD)
Text(long, wrap = true, maxLines = 2, lineHeight = 20, align = TextAlign.CENTER)
Text("ДОСТИЖЕНИЯ", size = Theme.TEXT_CAPTION, tracking = 2)   // разрядка, как у small caps
```

Текст меряет себя сам, поэтому панель вокруг него садится точно по нему. Длинная строка
переносится по словам; `maxLines` обрезает с многоточием; `wrap = false` запрещает перенос
(нужно для строк в ряд, которые не должны «сложиться»).

Строка из кусков с разным оформлением — `RichText`:

```kotlin
RichText(listOf(
    Span("VOID", Theme.INK, Weight.BOLD),
    Span("RP", Theme.VIOLET_SOFT, Weight.BOLD),
), size = Theme.TEXT_LEAD)
```

## Сетка

```kotlin
Grid(
    columns = 3,
    gap = Theme.SPACE_2,
    rowGap = Theme.SPACE_2,
    grow = true,        // ряды делят лишнюю высоту панели между собой
    children = tiles,
)
```

Все ячейки одного размера — по самой большой. Число колонок можно считать от экрана:
`viewport.columns(ideal = 260, min = 2, max = 5, gap = Theme.SPACE_3)`.

## Прокрутка

```kotlin
Scroll(children = rows, offset = scroll, gap = 8, bar = true, id = "list")
```

`offset` хранит страница: колесо мыши меняет число, страница рисуется заново. Обрезать
глиф на полпути нельзя (он рисуется целиком или никак), поэтому прямоугольники режутся по
краю окна, а слова и иконки показываются, только пока влезают целиком.

Ползунок можно таскать мышью — `scrollFromBar(scroll, id, viewport.width, viewport.height)`
из `ru.voidrp.ui.widget` переводит положение курсора в новый `offset`.

## Поверх всего

```kotlin
Overlay(dropdown())   // занимает место как обычный ребёнок, но рисуется последним
```

Выпадающий список в обычном потоке раздвигает панель при открытии и оказывается под теми,
кто идёт после него. Внутри `Overlay` он не двигает ничего и рисуется поверх.

## Ручное размещение

```kotlin
Raw(Rect(0, 0, viewport.width, viewport.height, tint))   // координаты от угла родителя
```

`Raw` не занимает места и ничего не двигает — для звёзд на фоне, подсветки внутри карточки
и прочего, чему в раскладке ещё нет слова.

## Пустота

```kotlin
Gap(size = 12)          // просто пустое место
Gap(grow = true)        // растяжка: разносит соседей по краям
```

## Области, наведение, клики

Панель с `id` запоминается при раскладке, и дальше всё происходит на сервере:

```kotlin
Panel(
    id = "tile:market",
    style = if (hovered == "tile:market") Theme.card.hover() else Theme.card,
    children = listOf(Icon("cart"), Text("Рынок")),
)

override fun onClick(id: String, button: Button) {
    if (id == "tile:market") push(MarketPage())
}
```

Подробнее о событиях — в [странице](страница.md).

## Чего в раскладке нет

- **Абсолютного позиционирования** — кроме `Raw`, и это сознательно: страница, набранная
  координатами, ломается на первом же экране другой формы.
- **Переноса в ряду** (`flex-wrap`) — для сеток есть `Grid`, а ряд, который переносится
  сам, чаще всего означает, что нужна сетка.
- **Клиппинга по произвольной форме** — глиф рисуется целиком; режется только
  прямоугольниками (этим занимается `Scroll`).
