# Курсор от клиентского мода (Origins)

Мод `voidrp_client_info` открывает пустой прозрачный экран, пока открыта страница: курсор —
системный, мод шлёт серверу позицию мыши, кнопки, колесо и клавиши. Без мода — курсор взглядом.

Протокол (big-endian):
- `voidrp:ui_screen` сервер → клиент: `op:byte arg:byte`. op 1 — открыть (и «я ещё здесь» после Esc),
  0 — закрыть, 2 — форма курсора (arg 0 стрелка, 1 рука, 2 текст).
- `voidrp:ui_input` клиент → сервер, 9 байт: `kind:byte a:short b:short c:int`.
  1 движение (a, b = x от центра и y в единицах холста), 2 кнопка (a, b, c = button<<1 | down),
  3 колесо (a, b, c = ±1), 4 клавиша (c = код GLFW, a = модификаторы), 5 символ (c = code point),
  6 экран закрыт клиентом, 7 размер окна (a, b = ширина и высота в пикселях).

- [x] Плагин: каналы, `ClientPointer`, режим сессии «курсор от клиента», размер окна → Viewport
- [x] Мод: payload'ы, `PointerScreen`, отправка ввода, форма курсора, возврат после диалога, страховка Esc
- [x] Стенд: NeoForge-клиент с модом — позиция, наведение, клик, колесо, Esc
- [ ] Итог и решение о выпуске (пак Origins + плагин)

## Стенд (12.10, NeoForge 26.2.0.88 + voidrp_client_info 1.2.0)

- Наведение, клик, колесо в списке магазина, Esc назад / Esc закрыть, ввод в диалоге и возврат после него — работают.
- Плагин загружен после входа игрока → `sendSupportedChannels()` при регистрации, иначе мод молчит.
- Выгрузка плагина: Bukkit не даёт выключенному плагину слать сообщения; мод сам снимает экран, когда наших
  белых пустых баров нет 1,5 с.
- Чужой босс-бар выше наших сдвигает страницу на 19 единиц на каждый — мод вычитает это из позиции.
- Смена страницы через `open`: «закрыть» откладывается на тик и не уходит, если сразу открылась другая.
