# Готовые элементы

![Элементы: кнопки, флажки, ползунки, списки](states.png)
![Элементы: вкладки, переключатели, плитки, сообщения, диалоги](states-2.png)

Всё это — обычные функции в `ru.voidrp.ui.widget`, которые возвращают `View`. Никакого
собственного состояния у них нет: состояние хранит страница, а элемент только показывает
его и сообщает, что его нажали. Поэтому расходиться с данными им нечем.

Те, что реагируют на курсор, объявлены как расширения `Page` — им нужно знать, на что
наведён курсор:

```kotlin
import ru.voidrp.ui.widget.*

override fun view(): View = screen(style = Theme.scrim, align = Align.CENTER, children = listOf(
    card("Профиль", icon = "user", children = listOf(
        statTile("Баланс", "184 200", "coins", accent = Theme.GOLD),
        button("Открыть рынок", "market", Theme.buttonPrimary),
    )),
))
```

## Каркас

| | |
|---|---|
| `screen(style, direction, justify, align, gap, children)` | корень страницы: панель ровно по экрану игрока |
| `card(title, children, icon, trailing, style, width, height, gap)` | карточка с заголовком; `trailing` — что положить справа от заголовка |
| `divider(width, paint)` | волосяная черта |
| `eyebrow(text, colour, size, tracking)` | мелкая разрядка капсом — надзаголовок |
| `chip(text, style)` | пилюля: версия, режим, состояние |
| `emptyState(title, hint, icon)` | «здесь пусто» — приглашение, а не извинение |
| `notice(text, tone, width)` | строка с цветом: `Tone.INFO`, `GOOD`, `WARN`, `BAD` |

## Нажимаемое

| | Сообщает |
|---|---|
| `button(caption, id, style, width, height)` | `id` |
| `iconButton(icon, id, size, style, selected, iconSize)` | `id` |
| `tabs(id, tabs, selected, height)` | `"<id>:<ключ>"` |
| `checkbox(label, id, checked, style, width)` | `id` |
| `toggle(id, on, label)` | `id` |
| `stepper(id, value, style)` | `"<id>:-"` и `"<id>:+"` |
| `select(id, options, selected, open, width)` | `id` у закрытого, `"<id>:option:<индекс>"` у пункта |
| `slider(id, value, width, height)` | `id`; куда именно попали — `sliderValue(id)` |
| `dialog(id, title, text, yes, no, tone, width)` | `"<id>:yes"` и `"<id>:no"` |

Всё нажимаемое подсвечивается само: элемент знает `hovered` и берёт стиль поярче.

## Показывающее

| | |
|---|---|
| `statTile(label, value, icon, style, width, accent)` | число со словом под ним — из этого собирается дашборд |
| `progress(caption, value, valueText, colour, width)` | полоса с подписью и значением |
| `tooltipPanel(title, lines, width)` | подсказка у курсора — отдавайте её из `tooltip()` |

## Как это выглядит в странице

```kotlin
class MarketPage : Page() {

    private var tab = "all"
    private var confirming: String? = null

    override fun view(): View = screen(style = Theme.scrim, align = Align.CENTER, children = listOf(
        card(
            "Рынок",
            icon = "market",
            trailing = tabs("tab", listOf("all" to "Все", "arms" to "Оружие"), tab),
            children = listOf(
                if (items.isEmpty()) emptyState("Пока ничего не продают")
                else Grid(columns = viewport.by(compact = 3, regular = 4), children = items.map { tile(it) }),
            ),
        ),
        // Диалог стоит над страницей, поэтому он в Overlay.
        confirming?.let { Overlay(dialog("sell", "Продать за 120 ₽?", "Отменить будет нельзя.", tone = Tone.BAD)) }
            ?: Gap(0),
    ))

    override fun onClick(id: String, button: Button) = when {
        id.startsWith("tab:") -> { tab = id.removePrefix("tab:"); refresh() }
        id == "sell:yes" -> { sell(confirming!!); confirming = null; refresh() }
        id == "sell:no" -> { confirming = null; refresh() }
        else -> Unit
    }
}
```

## Свой элемент

Никакого API для этого не нужно: элемент — это функция, возвращающая `View`.

```kotlin
fun Page.priceTag(item: String, price: Int): View = Panel(
    style = if (hovered == "buy:$item") Theme.cardAccent else Theme.card,
    direction = Direction.ROW,
    gap = Theme.SPACE_2,
    align = Align.CENTER,
    id = "buy:$item",
    children = listOf(
        Image(item, 24),
        Text(name(item), Theme.TEXT_BODY, Theme.INK, wrap = false),
        Panel(width = Size.Fill),
        Text("$price ₽", Theme.TEXT_BODY, Theme.GOLD, TextFonts.Weight.BOLD, wrap = false),
    ),
)
```

Если элемент пригодится всем — присылайте в проект, место ему здесь.
